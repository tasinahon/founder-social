Facebook Configuration

📋 Setup Instructions

  1. Go to Facebook Developers
  2. Create an app and get your App ID and App Secret
  3. Add "Pages" permissions to your app
  4. Generate a Page Access Token for your Facebook page
  5. Find your Page ID in your Facebook page settings

LinkedIn Configuration

📋 Setup Instructions

  1. Go to LinkedIn Developers
  2. Create an application and get your Client ID and Client Secret
  3. Request "Share on LinkedIn" and "Marketing API" permissions
  4. Generate an access token with proper scopes
  5. Get your company/organization ID if posting as company

Twitter/X Configuration

📋 Setup Instructions

  1. Go to Twitter Developer Portal
  2. Create an application and get API keys
  3. Generate access tokens with read/write permissions
  4. Ensure your app has "Tweet" permissions enabled
  5. Get your Bearer Token for enhanced features
