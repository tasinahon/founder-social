Platform Setup Guide

{% if platform == 'twitter' %}

Twitter/X Setup

  1. Go to Twitter Developer Portal
  2. Create a new app or use an existing one
  3. Enable OAuth 2.0 with PKCE
  4. Add redirect URI: http://localhost:8000/auth/twitter/callback
  5. Copy Client ID and Client Secret to your config
{% elif platform == 'linkedin' %}

LinkedIn Setup

  1. Go to LinkedIn Developers
  2. Create a new app
  3. Request access to Marketing Developer Platform
  4. Add redirect URI: http://localhost:8000/auth/linkedin/callback
  5. Copy Client ID and Client Secret to your config
{% elif platform == 'facebook' %}

Facebook Setup

  1. Go to Facebook Developers
  2. Create a new app
  3. Add Facebook Login product
  4. Add redirect URI: http://localhost:8000/auth/facebook/callback
  5. Copy App ID and App Secret to your config
{% elif platform == 'instagram' %}

Instagram Setup

  1. Go to Facebook Developers
  2. Create a new app or use existing Facebook app
  3. Add Instagram Basic Display product
  4. Add redirect URI: http://localhost:8000/auth/instagram/callback
  5. Copy App ID and App Secret to your config
